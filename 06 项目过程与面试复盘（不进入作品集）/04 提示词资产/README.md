# 提示词资产说明

## 提示词分层

| 类型 | 用途 | 保存位置 |
|---|---|---|
| 项目协作 Prompt | 约束后续开发、文档与验证方式 | 本目录 |
| 内容生产 Prompt | 生成或更新 PRD、研究、技术方案、作品集 | 本目录 |
| 产品运行 Prompt | `02 技术设计/Prompt设计.md` 及后续代码配置 | 见 [产品运行Prompt索引-v1.0.md](./产品运行Prompt索引-v1.0.md) |

## 真实性说明

项目早期没有保存生成现有文档和代码时使用的原始 Prompt。因此本目录中的“历史内容提示词”是依据现有产物反向整理的重建版，不是原始聊天记录。其作用是支持后续复现、评审和版本迭代，不能被描述为完整的历史审计记录。

## 版本规则

- 内容或结构变化：次版本 `v1.0 -> v1.1`。
- 输入输出契约变化：主版本 `v1.x -> v2.0`。
- 每次变化必须在开发日志中记录原因、关联文件和验证结果。
