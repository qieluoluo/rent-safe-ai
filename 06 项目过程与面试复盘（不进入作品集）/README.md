# 项目过程与面试复盘

本目录保存租安 AI 的内部过程材料，不进入公开作品集。

## 目录说明

| 目录 | 用途 |
|---|---|
| `01 开发日志` | 每次任务的实现过程、逻辑、取舍、验证和遗留问题 |
| `02 产品经理` | 通用产品经理面试问答与技能知识点 |
| `03 AI产品经理` | AI 产品经理面试问答与技能知识点 |
| `04 提示词资产` | 项目协作提示词、内容生成提示词和产品运行 Prompt 的索引 |

## 使用规则

- 日志按 `YYYY-MM-DD-任务名称.md` 命名。
- 已知事实、模拟数据、设计假设和真实结果必须分开记录。
- 历史原始 Prompt 不存在时，只能保存“重建版提示词”，并明确标注。
- 面试答案必须以当前仓库真实实现为准；能力尚未落地时使用“设计了”“规划了”“搭建 Mock 基线”等准确动词。
