### 2.2 对比结论（差异化机会）

```
租安AI的三个重点差异化方向（当前观察中覆盖相对较少，仍需持续验证）：
  1. 证据智能管理（AI分类+提取+评分+缺失提示）
  2. 标准纠纷分析路径（7节点Agent工作流+多轮追问+版本管理）
  3. 行动指南（可复制话术+具体投诉渠道）

通用法律AI在本轮观察中的主要机会点：
  · 覆盖场景广，租房专项流程的深度需逐产品评测
  · 生成式能力存在引用或时效信息错误风险
  · 案件级证据整理能力在当前观察样本中覆盖较少

通用大模型在本轮观察中的主要机会点：
  · 法条与渠道信息准确性需要统一测试集验证
  · 行动步骤的具体性受提示方式影响
  · 主动追问的结构与稳定性需要评测

  · 以权威公共法律服务和人工咨询为主，服务时效受地区与渠道影响

```

## 三、竞品详细分析

### 3.1 竞品1：通用法律AI产品（法律先生/法律AI助手类）

**产品定位：** 全场景法律AI助手，覆盖婚姻/劳动/交通/刑事/合同等

**我们看的具体产品：** 法律先生、法宣在线AI、元典智库

**核心能力：**

```
· 法律问答（通用）
· 合同审查（通用）
· 文书生成（起诉状、合同模板）
· 法条检索
```

**观察到的优点（需按具体产品版本复核）：**

- 法律知识库通常比通用AI更聚焦
- 部分产品有引用法条来源

**相对机会点（待统一任务评测）：**

| 观察到的机会点 | 租安AI规划如何差异化 |
|------|-----------------|
| ① 覆盖场景广，押金纠纷专项流程深度需评测 | V1聚焦押金纠纷，设计标准要素清单和标准路径 |
| ② 案件级证据管理在当前观察样本中较少见 | 规划证据智能分类+提取+评分+缺失提示 |
| ③ 回答与后续行动的衔接程度因产品而异 | 将行动指南纳入V1 P0，提供step-by-step路径+话术模板 |
| ④ 对焦虑用户的表达方式需体验评测 | 采用克制、易懂的表达，降低用户理解与行动成本 |

**一句话总结：** 通用法律AI覆盖面更广；租安AI计划以押金纠纷的证据与行动闭环形成场景深度。

### 3.2 竞品2：贝壳找房 / 自如APP

**产品定位：** 租房平台，匹配房源+签约+服务

**法律服务观察摘要（需按最新版本复核）：**

```
自如（省心租）：
  · 提供平台标准合同，条款协商空间需结合具体业务核验
  · 有管家客服（出问题找管家）
  · 本轮未重点观察到独立的AI纠纷分析入口

贝壳找房：
  · 房源平台，对接中介和房东
  · 平台提供交易与客服相关服务，C端法律服务边界需核验
  · 本轮未重点观察到独立的AI纠纷分析入口
```

**服务边界与机会点：**

| 观察到的服务边界 | 租安AI规划的切入点 |
|------|---------------|
| ① 服务目标主要围绕平台交易链路 | 租安AI从租客需求出发提供中立的信息整理与风险提示 |
| ② 服务覆盖可能受平台订单与合同体系限制 | 规划支持不同租房渠道产生的押金纠纷材料 |
| ③ 房源交易与履约服务是其主要产品重点 | 租安AI专注纠纷发生后的证据和行动辅助 |
| ④ 标准合同的修改空间可能有限 | 合同风险检测作为后续版本能力，支持用户上传自有合同 |

**一句话总结：** 租房平台重点服务找房和履约；租安AI计划补充押金纠纷发生后的信息整理与行动辅助。

### 3.3 竞品3：ChatGPT / 文心一言等通用大模型

**产品定位：** 通用AI助手，回答所有问题

**租房场景下的单轮体验示例（非系统评测）：**

> 以下回答仅用于展示统一测试题的设计方式，不代表该产品在不同版本、模型和提示下的稳定表现。

```
用户问题："房东以墙面损坏为由不退3500押金合法吗？"

ChatGPT回答：
"这要看具体情况：
1. 如果是正常使用损耗，房东不应扣押金，参考《民法典》关于租赁合同的规定；
2. 如果是故意或过失损坏，房东有权扣除维修费用。
建议你和房东协商，协商不成可以通过诉讼解决。"
```

**由该示例提出的待验证问题：**

| 待验证问题 | 租安AI规划怎么解决 |
|------|---------------|
| ① 结论可能偏概括 | 在证据与适用范围明确时输出带依据的风险提示，避免胜诉承诺 |
| ② 主动追问结构是否稳定 | 用要素清单标准追问；V1暂以完整度≥80%进入分析，该阈值为待评测校准的产品假设 |
| ③ 话术是否需要用户反复提示 | 将可编辑的协商话术纳入V1 P0行动指南 |
| ④ 法条引用可能存在错误风险 | 用RAG+幻觉校验节点，引用必须来自知识库 |
| ⑤ 案件级证据管理需跨轮组织 | 规划证据上传+分类+提取+评分+缺失提示 |
| ⑥ 渠道信息存在过期或错误风险 | 知识库维护权威渠道并标注更新时间，不依赖LLM自由发挥 |

**一句话总结：** 通用大模型能力覆盖广；租安AI计划用押金纠纷要素、证据目录和行动路径提供更稳定的场景化体验。

### 3.4 竞品4：12348中国法网（官方公共法律服务）

**产品定位：** 司法部官方平台，免费法律咨询+法律援助

**服务形式：**

```
  · 12348热线（具体服务时间以当地最新公告为准）
  · 12348法网（在线服务形式与响应时间以官方最新说明为准）
  · 线下公共法律服务（办理条件与地点因地区而异）
```

**优点：**

- 免费
- 律师专业，有资质

**服务差异（需按地区和渠道核验）：**

| 可能的体验差异 | 租安AI规划怎么衔接 |
|------|---------------|
| ① 人工热线在高峰期可能存在等待 | 目标是提供可随时发起的前置信息整理 |
| ② 在线服务响应时间因渠道而异 | 目标是先生成即时的结构化初步结果，并提示其非专业法律意见 |
| ③ 人工服务与AI标准流程侧重点不同 | 用可评测的工作流提高输出一致性，同时保留专业咨询升级路径 |
| ④ 用户通常需要主动准备和说明材料 | AI规划帮助整理材料并提示缺失证据 |
| ⑤ 具体沟通支持因服务渠道而异 | V1规划生成可编辑话术 |

**一句话总结：** 12348是权威公共法律服务渠道；租安AI定位为前置辅助，先帮助用户整理事实、证据和行动选项，必要时再引导至官方或专业服务。

## 五、竞品分析结论（差异化战略）

### 5.1 租安AI的三项差异化能力建设方向

```
方向1：押金纠纷场景深度
  · V1围绕押金纠纷定制要素清单；其他纠纷进入后续版本
  · 专属知识库（不是通用法律知识）
  → 通过持续维护场景规则、知识来源和评测集形成体验优势

方向2：证据智能管理系统
  · OCR+LLM提取关键信息
  · 证据重要度评分算法
  · 缺失证据智能推荐
  → 当前观察样本中覆盖较少，是否形成显著差异需用统一任务评测验证

方向3：案件-证据-报告反馈闭环
  · ai_task表记录每次AI调用
  · 用户反馈优化Prompt
  · 历史案例沉淀→知识库补充
  → 在取得用户授权、完成脱敏并通过效果评测后，逐步形成可持续优化闭环
```

### 5.2 一句话定位（市场宣传语）

```
从"相关规则是什么"，
到"结合你的材料，下一步可以怎么做"。
```

### 5.3 MVP切入策略

```
一句话：先用"押金纠纷"这一个场景验证完整闭环，再逐步扩展。

为什么选押金纠纷（以下均为待真实研究验证的产品假设）：
  · 模拟问卷假设中68%的样本遇到过（非真实调研结果，待验证）
  · 痛感较强（直接涉及押金损失）
  · 判断要素相对集中（合同约定、损耗性质、维修凭证等）
  · 证据链较适合标准化（合同+转账+聊天+照片）
  · 用户存在低成本维权诉求（具体金额分布待真实调研验证）
```
