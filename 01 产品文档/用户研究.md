## 一、研究背景

```
1. 目标用户是谁？（用户画像）
```

## 二、用户画像（Persona）

> 以下画像均为基于典型场景构建的模拟 Persona，不对应任何真实受访者。

### 画像1：职场新人 小李（22岁）—— 典型押金纠纷用户

```
┌─────────────────────────────────────────────────┐
│ 【姓名】小李            【年龄】22                │
│ 【身份】大学毕业生        【城市】上海             │
│ 【职业】运营岗新人        【月薪】税前8k          │
│ 【租房经验】第1次租房     【租期】1年             │
└─────────────────────────────────────────────────┘
```

**背景：**

- 刚从外地大学毕业，入职上海一家互联网公司
- 通过租房平台整租了一间1居室，月租3500元，押一付三
- 合同条款完全没看，直接签了

**遇到的纠纷：**

> 租期到了退房，房东说墙面有小孩涂鸦（实际是上一户留下的）、地板有正常磨损，扣除全部3500元押金。

**当前行为：**

1. 先百度搜"房东不退押金怎么办"，信息零散，越看越乱
2. 打了12345，客服说需要整理合同、转账记录、聊天记录，不知道怎么整理
3. 咨询了一个律师朋友，律师说"金额太少不值得走诉讼"
4. 现在不知道怎么办，已经拖了3周，想放弃了

**核心痛点：**

```
① 不懂法：不知道"正常损耗不赔"这条法律
② 证据散：合同、聊天记录、转账记录、照片散落在各处
③ 不知道下一步：不知道先协商还是直接投诉，没有明确的行动路径
④ 怕麻烦：3500元，跑法院花的时间精力觉得"不值"
```

**情绪状态：** 焦虑 + 觉得"吃哑巴亏算了"

**对产品的期望：**

> "就想有人告诉我，我这个情况到底能不能要回来，需要准备什么，第一步先干什么。"

### 画像2：租房老司机 小王（28岁）—— 多纠纷老手

```
┌─────────────────────────────────────────────────┐
│ 【姓名】小王            【年龄】28                │
│ 【身份】产品经理          【城市】深圳             │
│ 【职业】互联网产品经理    【月薪】税前25k         │
│ 【租房经验】6年4次租房    【租期】第5套           │
└─────────────────────────────────────────────────┘
```

**背景：**

- 6年换了5个房东，每个都有纠纷
- 学过一点法律（罗翔视频看了不少），但还是不系统
- 上次退租，房东扣了他1500元维修费，他协商了3次没成功，最后打12315投诉要回来了

**遇到的纠纷：**

> 第6次租房，合同里写了"本合同最终解释权归房东所有"、"所有维修费用租客承担"，签字前觉得不对劲，但不知道哪些是无效条款。

**当前行为：**

1. 提前研究租房避坑帖子，存了一堆截图
2. 这次签合同前，对照"租房避坑清单"一条条看，但还是拿不准
3. 想找个律师审一下合同，报价500元，觉得"合同就3页纸，500元太贵了"

**核心痛点：**

```
① 合同看不懂：不知道哪些条款合法、哪些是无效的霸王条款
② 预防难：纠纷发生前想检查合同，但找不到便宜靠谱的方式
③ 经验零散：每次自己总结的经验散落在笔记里，不成系统
```

**情绪状态：** 谨慎 + 觉得"找律师性价比低"

**对产品的期望：**

> "签合同前帮我扫一眼，哪些条款是坑，大概告诉我就行，不用律师那么细。"

### 画像3：宝妈 张姐（34岁）—— 维修责任用户

```
┌─────────────────────────────────────────────────┐
│ 【姓名】张姐            【年龄】34                │
│ 【身份】全职妈妈          【城市】广州             │
│ 【职业】无（带孩子）      【家庭收入】月1.5万      │
│ 【租房经验】2年第1次     【租期】还剩10个月       │
└─────────────────────────────────────────────────┘
```

**背景：**

- 老公一个人工作，经济压力大，租房是因为孩子要在附近上学
- 租的是老小区2居室，家电都比较旧

**遇到的纠纷：**

> 空调坏了，叫房东修，房东说"你自己弄坏的自己修"，张姐说"我正常用的怎么就我弄坏了"。房东一直拖延，现在夏天没空调，孩子晚上睡不着。

**当前行为：**

1. 和老公吵架，老公说"算了自己花钱修吧，别折腾了"
2. 不知道空调坏了到底该谁修，网上说法不一
3. 想找房东又怕房东说"不租了你们搬走"，孩子转学太麻烦

**核心痛点：**

```
① 怕被赶：维权怕房东报复，不租了更麻烦
② 责任不清："正常使用坏了谁修"这个问题搞不懂
③ 时间紧：孩子要上学，希望问题快点解决，不想拖
④ 沟通难：不知道怎么和房东说才不会被拒绝
```

**情绪状态：** 委屈 + 焦虑 + 无助

**对产品的期望：**

> "帮我判断一下到底该谁修，给我一段复制就能发的话，最好让房东看了就同意修。"

### 画像4：大学生 小陈（20岁）—— 提前退租用户（潜在高频用户）

```
┌─────────────────────────────────────────────────┐
│ 【姓名】小陈            【年龄】20                │
│ 【身份】大三学生          【城市】杭州             │
│ 【职业】实习准备中        【月生活费】2500         │
│ 【租房经验】第1次         【租期】6个月合租       │
└─────────────────────────────────────────────────┘
```

**背景：**

- 暑假实习，和两个同学合租了一套房，月租每人1200元，押一付一
- 实习2个月后，公司offer取消了，需要提前退租

**遇到的纠纷：**

> 房东说"签了6个月合同，提前走押金不退，还得付1个月违约金"。合同里确实有这条，但3个学生每人1200押金+1200违约金，总共要亏7200元，对他们来说是大数目。

**当前行为：**

1. 3个同学开了个小会，查了一晚上法律条文，越查越糊涂
2. 觉得"合同签了就该认"，但又心疼钱
3. 不知道违约金太高能不能找法院减少
4. 家里条件一般，不敢跟爸妈说

**核心痛点：**

```
① 金额大：对学生来说几千块是大数目，真亏不起
② 不懂条款效力：不知道合同签了是不是必须认，不知道违约金过高可以调整
③ 信息不对称：不知道该和房东怎么谈，没底气
④ 社会经验少：怕被房东吓唬住
```

**情绪状态：** 慌乱 + 委屈 + 怕父母担心

**对产品的期望：**

> "帮我看看合同这条是不是太过分了，如果我去协商有胜算吗？给我点底气。"

## 三、用户痛点地图（Pain Point Map）

### 3.1 按用户旅程拆解痛点

```
租房用户旅程：
【看房 → 签合同 → 入住 → 租期内 → 退租 → 纠纷处理】
    │        │        │        │       │        │
    ▼        ▼        ▼        ▼       ▼        ▼
  踩坑A    踩坑B    踩坑C    踩坑D   踩坑E    踩坑F
```

### 3.2 痛点详解

| 阶段 | 痛点 | 严重程度 | 发生频率 | 用户心声 |
|------|------|---------|---------|---------|
| **签合同前** | 不知道哪些条款是霸王条款 | ★★★★ | 高（每次签） | "这些字我都认识，但不知道合不合法" |
| **签合同前** | 合同条款太多，看不下去 | ★★★ | 高 | "5页纸，根本看不完，直接签了" |
| **入住时** | 不知道该拍哪些照片留证据 | ★★★★ | 高 | "当时没拍，现在说不清楚了" |
| **租期内** | 家电坏了不知道谁修 | ★★★★★ | 极高 | "房东说是我弄坏的，我觉得正常用，扯不清" |
| **租期内** | 房东临时涨房租/要卖房 | ★★★★ | 中 | "突然说要卖房子，让我1个月搬走" |
| **退租时** | 房东扣押金 | ★★★★★ | 极高 | "各种理由扣押金，有的是正常损耗也扣" |
| **退租时** | 不知道哪些扣钱是合法的 | ★★★★★ | 极高 | "他说我弄坏的，我觉得不是，但说不清" |
| **纠纷后** | 证据散落各处，不知道整理哪些 | ★★★★★ | 极高 | "聊天记录、转账、照片，乱七八糟，不知道哪些有用" |
| **纠纷后** | 不知道先协商还是直接投诉/起诉 | ★★★★★ | 极高 | "怕麻烦，但又不想吃亏，不知道第一步先干嘛" |
| **纠纷后** | 话术不知道怎么说才不被拒绝 | ★★★★ | 极高 | "跟房东沟通总是被绕进去，说不过他" |
| **纠纷后** | 金额太小不想找律师 | ★★★★ | 高 | "2000块找律师最低要3000，不值" |

### 3.3 痛点优先级排序

```
★★★★★ 核心痛点（必须解决）：
    1. 退租时房东扣押金（是否合法不清楚）
    2. 租期内维修责任分不清
    3. 证据散落，不知道怎么整理
    4. 不知道纠纷后的行动路径
    5. 不知道怎么沟通才有底气

★★★★ 重要痛点（应该解决）：
    1. 合同看不懂（风险条款识别）
    2. 违约金过高能不能减
    3. 房东临时涨租/赶人怎么办

★★★ 一般痛点（可以延后）：
    1. 合同太长看不下去
    2. 入住时不知道拍什么
    3. 找律师贵
```

## 五、模拟用户研究推导（产品方向输入，待验证）

### 5.1 核心发现

| 发现 | 对产品的启示 |
|------|-------------|
| **结论1：用户缺的不是信息，是"判断+行动"** | 不要做成法律知识库，要做成"你这个情况XX，第一步做YY"的决策辅助 |
| **假设2：证据管理是候选差异化机会** | 当前案头观察中案件级证据整理覆盖较少，应作为重点验证方向，而非既定壁垒 |
| **结论3：用户需要"底气"** | 不只是给建议，还要给话术模板、法律依据，让用户沟通时"有话可说" |
| **结论4：成本感知强** | 几千块请律师不值，产品必须免费或极低成本，AI刚好能做到 |
| **结论5：时间紧迫+怕麻烦** | 必须"即问即用"，不要让用户填十几项表单才出结果 |

### 5.2 产品优先级输入

```
P0必须做（基于模拟研究的待验证优先级）：
  √ 押金纠纷分析（模拟研究中频率与痛感较高）
  √ 证据智能管理（候选差异化方向）
  √ 行动指南+话术模板（连接判断与行动）

后续版本（P1）：
  √ 维修责任纠纷分析（后续版本）
  √ 合同风险检测（后续版本，签字前预防）
  √ 提前退租+违约金分析（后续版本）

P2可以延后：
  ○ 律师对接（商业化方向）
  ○ 诉讼预测（太难+风险高）
  ○ 多城市法规差异（先通用，后细化）
```
