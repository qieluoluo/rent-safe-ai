# Mock 规则基线 v1.1

## 定位

确定性演示和评测基线，不是大模型 Prompt，也不是向量 RAG。

## 规则能力

- 判断是否属于 V1.0 押金纠纷范围。
- 抽取金额、争议角色、租约状态、扣款理由和争议关键词。
- 采用“核心字段门槛 + 权重得分”判断是否需要追问。
- 从两个带来源元数据的《民法典》片段中进行关键词知识匹配。
- 生成固定结构的风险提示、证据清单和行动建议。

## 元数据

| 项目 | 值 |
|---|---|
| 版本 | `mock-v1.1` |
| Provider | `mock` |
| 模型 | `rules-baseline` |
| 知识版本 | `civil-code-cn-2020-v1` |
| 数据 | `deposit-v1-synthetic.jsonl`，全部为合成用例 |
| 评测 | 运行 `evaluate_mock.py` 生成，不手填指标 |

## 相比旧版 Mock 的变化

- 将 V1 范围统一为押金纠纷，新增范围外识别。
- 完整度不再只判断字段是否为空，增加核心字段和可解释分值。
- 风险等级明确表示“信息准备度”，不冒充胜诉概率。
- 知识片段增加法条 ID、原文、来源、地域、生效日期和版本。
- 增加演示模式免责声明。
