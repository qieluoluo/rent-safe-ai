# 租安 AI 效果验证

## 数据性质

本目录中的用例全部是为工程验证编写的脱敏合成数据，不是真实用户案件，也不代表市场分布。真实模型结果与规则 Mock 结果必须分开保存。

## 当前基线

- `mock-v1.2`：当前确定性规则基线，用于验证产品流程、字段契约和评测脚本。
- `deposit-v1.0`：可选 OpenAI-compatible 模型 Prompt，尚未在本仓库中产生真实模型评测结果。
- 当前不存在可对外宣称的用户满意度、真实模型准确率或线上业务结果。

## 目录

| 目录 | 内容 |
|---|---|
| `测试案例` | 合成 Golden Set 与评测脚本输入 |
| `Prompt版本记录` | Prompt/规则版本、变化和验证状态 |
| `Bad Case优化记录` | 真实运行中发现的失败样本与回归记录 |
| `评测结果` | 由脚本生成的版本化结果，不手工修改 |

## 运行 Mock 基线

该脚本只使用 Python 标准库，不需要安装 FastAPI：

```powershell
python .\04 AI效果验证\evaluate_mock.py
```

输出会按当前规则版本写入 `评测结果/mock-baseline-v*.json`。指标只证明规则基线在当前合成集上的表现，不代表真实用户或大模型效果。

## 后续真实模型评测门槛

1. 固定模型、参数、Prompt版本和知识库版本。
2. 与同一用例集上的 Mock 及单次 LLM 基线比较。
3. 单独评估字段 F1、无效追问率、引用支持率、严重法律错误率、延迟和成本。
4. 真实模型失败必须进入 Bad Case 目录，并执行全量回归。
